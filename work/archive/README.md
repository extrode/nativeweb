# work/archive/

Completed tasklists, one file per shipped body of work, named `YYYY-MM-DD-<slug>.md` for the date
it shipped.

A tasklist arrives here when every entry is ticked and its outcome has been summarised into
`../../CHANGELOG.md`. `../tasklist.md` is then emptied and refilled for the next body of work.

Nothing here is edited after it lands. It is a record of what a body of work actually contained,
which the changelog deliberately does not keep.
